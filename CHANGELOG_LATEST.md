# buchcraft v0.2.1

Austrian double-entry ledger. Not a FinanzOnline filing tool. Local, one SQLite file. Windows x64.

## Downloads

- `buchcraft-app.exe`: the desktop window.
- `buchcraft.exe`: CLI and MCP server.
- `buchcraft-0.2.1-setup.exe`: per-user installer.
- `buchcraft-v0.2.1.mcpb`: MCP bundle.

## What is new

- The window menu is File, Edit, View, Window, and Help. `--smoke` checks the menu.
