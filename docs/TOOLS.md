# buchcraft MCP tools

Generated by `buchcraft tools --markdown`. Do not edit by hand: a test fails when this file
is out of date. Every tool is also a CLI verb (`buchcraft --help`). Dotted names (`app.verb`) are accepted.

| Tool | What it does | Required | Optional |
|---|---|---|---|
| `buch_status` | Ledger status: counts, open drafts, unmatched bank lines, closed periods, demo flag. | - | - |
| `buch_accounts_list` | List the chart of accounts (EKR). | - | - |
| `buch_accounts_seed` | Insert the EKR seed chart (existing numbers untouched). | - | - |
| `buch_account_add` | Add an account. | `number`, `name`, `kind` | `tax_key` |
| `buch_entry_book` | Book a balanced journal entry. Net lines carry a tax_key; the engine generates the tax lines. Lines (incl. generated tax) must sum to zero. | `date`, `kreis`, `description`, `lines` | `beleg_nr` |
| `buch_entry_book_gross` | Book a gross amount in one step: account gets net, engine adds tax, contra gets -gross. | `date`, `kreis`, `description`, `account`, `contra` | `beleg_nr`, `gross`, `gross_cents`, `tax_key` |
| `buch_entry_reverse` | Storno an entry (the only way to correct a booking). | `id`, `date`, `reason` | - |
| `buch_entry_show` | Show one entry with its lines. | `id` | - |
| `buch_journal` | Journal for a date range, optionally one Belegkreis. | `from`, `to` | `kreis`, `limit` |
| `buch_balance` | Saldenliste (debit, credit, balance per account) for a date range. | `from`, `to` | - |
| `buch_account_ledger` | Kontoblatt with opening and running balance. | `account`, `from`, `to` | - |
| `buch_u30` | U30 VAT pre-fill (Kennzahlen 000/006/022/029/060/065/070/072/095) for a month YYYY-MM. Not a filing. | `month` | - |
| `buch_period_close` | Close a month (YYYY-MM); later bookings dated in it are refused. | `month` | - |
| `buch_bank_import` | Import a bank statement CSV (German or English headers). Re-importing the same file adds nothing. Needs --allow-path. | `path` | - |
| `buch_bank_unmatched` | Bank lines not yet booked. | - | `limit` |
| `buch_bank_book` | Book an unmatched bank line against an account (gross; tax key splits it) and link it. | `id`, `account` | `description`, `tax_key` |
| `buch_drafts` | Drafts created from other apps' events (open only unless all=true). | - | `all` |
| `buch_draft_approve` | Book a draft. | `id` | - |
| `buch_draft_discard` | Discard a draft. | `id` | - |
| `buch_inbox_drain` | Read events from other craft apps (e.g. assetcraft depreciation) and turn them into drafts. | - | - |
| `buch_export_csv` | Export journal lines as semicolon CSV (DE format). Needs --allow-path. | `from`, `to`, `path` | - |
| `buch_demo_seed` | Fill an EMPTY ledger with a labelled demo company (October 2026). | - | - |
